# Library Management System

A robust backend RESTful Web API built using C# .NET and Entity Framework Core, designed to manage library operations efficiently.

## 🚀 Features
* **Book Management:** Add, view, update, and delete book records.
* **Database Integration:** Uses Entity Framework Core for reliable data persistence.
* **RESTful Architecture:** Clear endpoints for seamless integration.

## 🛠️ Tech Stack
* **Language:** C# (.NET Core)
* **Framework:** ASP.NET Core Web API
* **ORM:** Entity Framework Core
* **Database:** SQLite / Local DB
